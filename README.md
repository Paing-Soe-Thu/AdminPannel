# Admin Dashboard System

A simple Admin Dashboard web application built using Java and Spring Boot.  
This project allows admins to register, login, manage admin accounts, update information, and delete admin records.

---

## Features

- Admin Registration (Sign Up)
- Admin Login Authentication
- View Admin Dashboard
- View Admin List
- Update Admin Information
- Delete Admin Accounts
- Spring Boot MVC Architecture
- Database Integration using JPA/Hibernate

---

## Technologies Used

- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- MySQL
- HTML / CSS
- Thymeleaf
- Maven
